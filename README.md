# Midair.io（ミッドエア）

> **お試し公開URL**: https://music.wawa-app.me/Midair.io/
> （Cloudflare Tunnel による公開のため、サーバー停止中はアクセスできません）

周波数をダイヤルで合わせて各チャンネル（番組）に入る、24時間リアルタイム匿名BBS。
リスナーは「名無し」で聴き、やがて自分で周波数を取得して**開局（パーソナリティ）**へステップアップできる、ミニFM放送局システムです。

> **本リポジトリについて**: 開発成果物の紹介（サイト説明・技術説明）を目的としており、オープンソースとしてのセットアップ手順の提供・再利用・再配布は想定していません。

## サイト説明（できること）

### チューナー／掲示板（リスナー）

- **周波数チューナーUI** — ロータリーダイヤル／スライダーで周波数（76.0〜88.9MHz）を合わせてステーション移動。離したときに近くの局へスナップ（±0.1は長押しで連続調整）。
- **周波数帯の見分け** — ダイヤル位置に応じて OSD に `DEDICATED AREA / 専用局エリア`（専用局帯＝24時間常設）・`FREE AREA / 自由な周波数`（一般開局エリア）を表示。
- **リアルタイム匿名チャット** — WebSocket による低遅延メッセージ送受信。未ログインは「名無しのリスナー」として参加。
- **YouTube BGM 同期再生** — ステーションごとの楽曲をリスナー全員で同時再生（音ありが既定、自動再生不可時はワンタップで再生）。**曲が最後まで再生されたら、自動DJ局は次曲へ。それ以外の局は砂嵐（OFF AIR）**になり、最後の1曲がループし続けることはありません（番組枠の放送中は曲だけクリアして放送を維持）。停波した局は「今オンエア中の曲」もクリアするため、砂嵐の画面の裏で音が鳴り続けることもありません。
- **再生ログ** — ステーション画面の NOW PLAYING 欄に、その局で流れた曲の履歴を表示（**WebSocket でリアルタイム更新**：曲が切り替わるとリロードなしで先頭へ追加）。
- **AI ラジオ DJ Bot** — **「DJさん」「hey DJ」と呼びかけたときだけ**返事（大文字小文字・全角半角は問わない。`DJ_REPLY_REQUIRES_CALL=false` で従来どおり全メッセージに返信）。会話が途切れた際や「DJを呼ぶ」ボタンにも自動応答し、「DJ」として **LLM が自由生成**（定型文なし）。コメントは**今オンエア中の曲に連動**し、曲名・曲の印象・直前の曲の流れに触れます。**Gemini / OpenAI互換 API**（OpenAI・OpenRouter・Groq・**ローカル Ollama** など）に対応。未設定時は何も投稿しません。
- **DJの独り口（曲に連動）** — 無言の時間が続くと、DJが**約2分おきに独り口**を話します。内容は**今オンエア中の曲**（曲名・印象・直前の曲）に連動して変化します。曲が切り替わった瞬間の「曲紹介コメント」も用意していますが**既定は off**（`DJ_TRACK_INTRO_ENABLED=true` で有効）。
- **AIチャットbot常駐局「Miaちゃん」** — オタク天使のAIチャットbotが常駐するプリセット局（既定 88.0MHz）。リスナーを「**フォロワーちゃん**」と呼び、LLM が自由に返信。**Discord と双方向連携**：Midair→Discordへ転送し、Discordの投稿はMidairへ取り込み＋MiaがDiscord上でも返信します。

### 番組表・掲示板アーカイブ

- **番組表（タイムテーブル）** — 日別のラジオ番組表（EPG風）。番組の開始/終了に合わせて自動で ON AIR / 停波。
- **2chライクなスレッド** — 各局の掲示板はスレッド制。**1スレッド 1000 投稿**に達すると自動でアーカイブされ、次のスレッドが自動作成されます（第Nスレ）。
- **過去スレッド（アーカイブ）** — 過去の掲示板画面をそのまま閲覧できます（ログイン不要）。投稿番号・投稿者・時刻付き。
- **お気に入り周波数** — リスナーのプリセット保存。
- **フッター／サイト情報** — ホーム下部のフッターから**プライバシーポリシー・利用規約（免責）・サイトマップ・運営情報**をモーダルで表示（Esc・背景クリック・✕で閉じる）。**ハッシュ付きURLで直リンク**でき（`/#privacy`・`/#terms`・`/#sitemap`・`/#about`。Google の OAuth 認証で提出するポリシーURLにも使えます）、開くとURLのハッシュが変わり、閉じる／「戻る」で戻ります。

### 開局（パーソナリティ）

- **アカウント & 認証** — メール/パスワード登録 + JWT。Discord OAuth2 は環境変数設定時のみ有効。
- **開局システム** — 空き周波数の検索・取得、コールサイン／放送方針／AI DJ キャラクター設定。
- **スタジオコントロールパネル** — 開局した局の編集・BGM切替・ミュート・ON AIR/停波・廃局・番組管理。
- **プロフィール（マイページ）** — 保有局の管理・自分の過去の曲ログ・放送セッション・お気に入り。
- **パーソナリティ権限** — BGM強制切り替え・放送/休止切替・チャットモデレーション。

### はじめてのDJ（開局と運営）

> 操作に迷ったら、ヘッダー右上の**ヘルプ（?）**にサイト内の使い方をまとめています。

1. **開局** — 「周波数を探す」→「＋ 開局する」で **自由な周波数**（既定 80.0〜88.9MHz）の空きを選び、コールサイン・放送方針・AI DJ のキャラクターを設定。
2. **放送する** — 「スタジオ」で BGM 切替（YouTube URL）／ON AIR・停波／ミュート／番組表を操作。リスナーの「♪ リクエスト」はチャットに表示され、実際に流す曲はパーソナリティの操作（BGM 切替・番組の BGM 動画ID）で決まります。
3. **AI DJ に任せる** — スタジオの「AI DJ」を on にしてキャラクター設定（口調・呼び方）を書くと、**DJ として曲コメント・曲紹介・返信を LLM が自由生成**します。呼びかけは「**DJさん**」「**hey DJ**」（「DJを呼ぶ」ボタンでも可）で、呼びかけの無いメッセージには返信しません。無言が続いたときだけ DJ から話しかけます。
4. **24時間流す** — 放置された放送は切り忘れ対策で自動停波します（`AUTO_OFF_*`、停波前に予告）。常設したい場合は**専用局（24時間常設）**を申請してください（専用局帯＝既定 76.0〜79.9MHz からのみ申請可、自動停波の対象外）。
5. **おまかせで流す** — 登録不要の「DJ BOT」（84.0MHz）／「Vocaloid BOT」（85.0MHz）が24時間ランダム選曲でオンエア中。チャットで「DJさん」と呼べば返事をします。

### 周波数ライフサイクル

- **周波数マップ** `/frequencies` — 全スロットを**専用局帯 / 自由な周波数**の2ブロックに分けて表示。空きスロットから予約・開局（自由な周波数）、または専用局の申請（専用局帯）へ直接進めます。
- **全スロット管理** — 76.0〜88.9MHz（0.1MHz刻み）を `EMPTY / RESERVED / LIVE / OFF AIR` で一元管理。**総スロット数は変えずに2つの帯域に分けています**。
- **周波数帯の区分** — **専用局帯（既定 76.0〜79.9MHz）**＝24時間常設の専用局の申請専用（一般開局・時間枠予約は不可）。**自由な周波数（既定 80.0〜88.9MHz）**＝誰でも自由に開局・時間枠予約できる一般帯（専用局は作成不可）。境界は `DEDICATED_FREQ_MIN` / `DEDICATED_FREQ_MAX` で変更できます。
- **切り忘れ対策（自動停波）** — **ON AIR から既定6時間**、または**無人（リスナー0人・チャットなし）のまま既定2時間**で自動停波。停波の5分前に放送内で告知します。専用局（24時間常設）・自動DJ局・番組枠・終了予定付きの放送は対象外（`AUTO_OFF_*`）。
- **時間枠予約** — 周波数×時間帯の排他制御（重複は 409 で拒否）。予約は自由な周波数のみ。
- **リアルタイム同期** — 状態変化を WebSocket で全クライアントへ配信。OFF AIR は砂嵐表示。
- **廃局（周波数返還）** — 局を閉じてスロットを EMPTY に戻す。

### 自動DJ局（プリセット局）

24時間オンエアで**完全ランダムに選曲**し続ける、Discord の音楽Bot的な局。

- **「DJ BOT」**（既定 84.0MHz） — YouTube の人気曲チャート（mostPopular / ミュージック）から選曲。**再生数が多い曲ほど選ばれやすい**（人気曲優先）。直近30曲は重複を避ける。
- **「Vocaloid BOT」**（既定 85.0MHz） — **合成音声の歌唱を優先**。歌声（初音ミク／鏡音リン・レン／巡音ルカ／GUMI／IA・flower／ずんだもん など）・ジャンル（ロック／バラード／和風／ラップ など）・年代（新曲／名曲・殿堂入り）・プロデューサー（DECO*27／ピノキオピー／稲葉曇 など）・**歌声合成エンジン**（VOCALOID／Synthesizer V／CeVIO／VOICEROID／UTAU／NEUTRINO／VOICEVOX）別の検索テーマを巡回して候補プールを蓄積し、直近30曲と直近の投稿者の重複を避けて選曲。**公開日が浅い曲を控えめに後押し**し（公開30日以内の重みを1.6倍、`DJ_BOT_VOCALOID_FRESH_BIAS`。0で無効）、タイトルに歌声合成のクレジットがある曲は選ばれやすくする（`DJ_BOT_VOCALOID_SYNTH_BIAS`）。
- **DJの独り口** — 無言が続くと、その局のDJ（キャラクター設定）が**約2分おきに独り口**を話します。内容は**今オンエア中の曲**に連動（曲名・印象・直前の曲）し、BGMを切り替えると変化します。曲切替ごとの曲紹介コメントも実装済みですが**既定 off**（`DJ_TRACK_INTRO_ENABLED=true` で有効。連投防止 `DJ_TRACK_INTRO_COOLDOWN_SECONDS` / `DJ_TRACK_INTRO_REQUIRES_LISTENER`）。
- **選曲の足切り** — Shorts・90秒未満のクリップ、**1000再生以下の動画**、人の歌唱（歌ってみた・カバー）、**ボカロP本人の歌唱（セルフカバー・本人歌唱）**、別アーティストの動画（Eve・すとぷり等のカバー）やアルバム宣伝・クロスフェードは除外（タイトル・タグ・チャンネルで判定。人の歌唱・別アーティストの判定は Vocaloid BOT のみ）。さらに Vocaloid BOT は**歌声合成のクレジットが確認できない曲（インスト・クレジット無しの投稿）を流さない**（`DJ_BOT_VOCALOID_SYNTH_ONLY`、既定 on）。**曲が終わったら次曲へ**、**10分を超える長い曲は途中でスキップ**。**埋め込み可能な通常動画のみ**を採用し、再生に失敗した曲も自動で次曲へ。

### 専用局（24時間常設・申請承認制）

- **ロール** — `listener`（一般）/ `dedicated_owner`（専用局マスター）/ `admin`（管理者）。
- **申請→審査→承認フロー** — 希望周波数・コールサイン・ジャンル・コンセプト・初期音源リストを提出 → 管理者が承認/却下。
- **承認で本登録** — 周波数を固定した専用局を作成し、初期音源を音源プールへ移行、申請者を `dedicated_owner` へ昇格。
- **24時間自律運行エンジン** — リクエストキューを最優先 → 空なら音源プールからランダム送出。WebSocket で全リスナーへ即時同期。
- **管理ページ** `/admin` — 申請の承認/却下。管理者のみ表示。

## 技術説明

### 全体構成

```text
ブラウザ (SPA)
├─ Vue 3 (Composition API) + Vite + Vue Router 4 + Pinia
└─ 単一ソース (frontend/src) から Vite版 / スタンドアロン版を生成

バックエンド
├─ FastAPI (Python 3.9+) + Uvicorn + WebSockets
├─ SQLAlchemy（SQLite 既定 / MySQL 切替）
└─ APScheduler（専用局の自律運行）

公開: Cloudflare Tunnel + Cloudflare Worker（パス分岐）
```

### フロントエンド

- Vue 3 の単一ファイルコンポーネント（SFC）を**唯一のソース**（`frontend/src`）とし、Vite版とスタンドアロン版を同じ SFC からビルド。
- ルーティングは Vite版が履歴、スタンドアロン版がハッシュ（`#/...`）。API・WebSocket の接続先を環境で自動切替。
- モバイル最適化：ハンバーグメニュー、タップ領域の確保、固定高チャット＋「最新へ」ボタン、長い文字列のマーキー表示。
- YouTube IFrame Player API による公式埋め込み再生（YouTube 利用規約準拠）。

### バックエンド

- FastAPI + SQLAlchemy（async）による REST API と WebSocket（局チャット `/ws/{id}`・ロビー `/ws`）。
- JWT + bcrypt による認証。ロール（`listener` / `broadcaster` / `dedicated_owner` / `admin`）で権限分離。
- **周波数の実装** — 帯域の判定・検証は `core/bands.py`（`DEDICATED_FREQ_MIN/MAX` から専用局帯を算出し、残りを自由な周波数として扱う）。切り忘れ対策は `services/auto_off.py` を `main._lifecycle_loop`（15秒間隔）から呼び出します。
- 周波数ライフサイクル、番組の自動 ON AIR/OFF AIR、放送セッションの自動記録をバックグラウンドで処理。
- AI DJ / AIチャットbot（LLMで自由生成。Gemini / OpenAI互換 API、**ローカル Ollama 対応**）、Discord 双方向連携、自動DJ局（人気曲/検索からランダム選曲）、専用局の自律運行（APScheduler）。

### AI / LLM

- AI DJ・AIチャットbot（Miaちゃん）は LLM で**自由生成**（定型文のリストは使わない）。プロバイダは `LLM_PROVIDER`（`auto` / `gemini` / `openai`）で切替。
- DJ のコメントは**今オンエア中の曲に連動**：アイドルDJ（無言の時間が続いたときの独り口）・「DJを呼ぶ」・チャット返信は、現在の曲名と直前の曲をプロンプトに渡します（`services/ai_dj.py` の各プロンプト）。曲名は選曲ログ → YouTube 情報の順で解決し、曲名が取れないときは動画IDを読み上げないよう「曲名不明」として扱います。曲切替時の曲紹介コメント（`services/dj_announce.py`）も実装済みですが**既定 off**です。
- **OpenAI 互換 API** に対応。OpenAI / OpenRouter / Groq / **ローカル Ollama**（例: `gemma3:12b`）などを `OPENAI_BASE_URL` の変更だけで利用できます。
- Miaちゃん局（88.0MHz）は **Discord Bot（discord.py Gateway）** と双方向連携。Midair・Discord の両方で Mia が返信し、会話は相互にミラーされます。
